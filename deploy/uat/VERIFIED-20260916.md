## Defect found and fixed during integration

Non-admin inventory export initially returned 500: Espo's default access checker
does not implement a custom `export` action. The fix checks built-in read access,
the global export permission, and the custom export level separately. Re-tested
successfully with all three real roles. Added regression coverage, including global
export denial. Local inventory assertions now total 19 (78 checks across all suites).
